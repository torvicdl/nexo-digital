Carro Autónomo Esquivador de Obstáculos

Diseñamos y ensamblamos un prototipo sobre ruedas capaz de detectar paredes y objetos en tiempo real sin chocar, usando lógica en Arduino y un sensor ultrasónico.

C++ / Arduino IDE Sensor HC-SR04 Puente H L298N Baterías 18650 (7.4V)

¿Cómo toma decisiones el robot?

El circuito combina la lectura del espacio con la respuesta inmediata de los motores en cuatro pasos simples:

01

Emisión del pulso

El sensor ultrasónico dispara un pulso de sonido imperceptible a través de su pin Trigger.

02

Rebote y Eco

La onda choca con el obstáculo más cercano y regresa al pin Echo del sensor.

03

Cálculo en la placa

El Arduino procesa cuánto tiempo tardó la onda en ir y regresar para calcular la distancia en centímetros.

04

Giro de emergencia

Si el objeto está a menos de 20 cm, detiene una rueda y gira sobre su propio eje para cambiar de dirección.

Componentes y Piezas Utilizadas

Este es todo el material que ocupamos para el armado técnico y la alimentación de energía del prototipo:

Placa Arduino Uno

Es la tarjeta principal que guarda la programación y coordina las órdenes entre las lecturas y las ruedas.

Chasis y 2 Motores DC

Base acrílica que soporta todo el circuito, incluye interruptor de encendido y motores con llantas de goma.

Controlador Puente H (L298N)

Etapa de potencia necesaria para cambiar el sentido de giro de los motores sin dañar la placa de control.

Sensor Ultrasónico HC-SR04

Funciona como los ojos del carrito, capaz de medir distancias de 2 cm hasta 4 metros.

Cables Macho-Macho

Utilizados para llevar la corriente y señales entre los pines principales de la placa y la protoboard.

Cables Macho-Hembra

Indispensables para conectar directamente las terminales del sensor de presencia y del puente H.

2 Baterías Li-Ion 18650

Pilas recargables de litio que dan el flujo de energía constante y suficiente para alimentar los motores.

Porta Pilas Doble

Base donde montamos las dos baterías conectadas en serie para sumar aproximadamente 7.4V en total.

Lógica del Algoritmo

carro_esquivador.ino 
// Definición de Pines del Sensor
const int trigPin = 9;
const int echoPin = 10;

// Pines para el control de motores (Puente H)
const int motorIzquierdo = 5;
const int motorDerecho = 6;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(motorIzquierdo, OUTPUT);
  pinMode(motorDerecho, OUTPUT);
}

void loop() {
  long duracion;
  int distancia;
  
  // Enviar pulso
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  duracion = pulseIn(echoPin, HIGH);
  distancia = duracion * 0.034 / 2; // Convertir a cm
  
  // Regla de decisión
  if (distancia < 20 && distancia > 0) {
    // Obstáculo detectado: Esquivar
    digitalWrite(motorIzquierdo, LOW);
    digitalWrite(motorDerecho, HIGH);
    delay(500);
  } else {
    // Camino libre: Avanzar
    digitalWrite(motorIzquierdo, HIGH);
    digitalWrite(motorDerecho, HIGH);
  }
}
