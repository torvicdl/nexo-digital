Carro Autónomo Esquivador de Obstáculos

Diseñamos y ensamblamos un prototipo sobre ruedas capaz de detectar paredes y objetos en tiempo real sin chocar, usando lógica en Arduino y un sensor ultrasónico.

C++ / Arduino IDE • Sensor HC-SR04 • Puente H L298N • Baterías 18650 (7.4V)

¿Cómo toma decisiones el robot?

El circuito combina la lectura del espacio con la respuesta inmediata de los motores en cuatro pasos simples:

01

Emisión Ultrasónica

El sensor HC-SR04 emite una ráfaga ultrasónica a 40 kHz a través del pin Trigger y espera el eco.

02

Cálculo de Distancia

El microcontrolador Arduino mide el tiempo del pulso devuelto y calcula la distancia en centímetros.

03

Evaluación de Lógica

Si la distancia es menor al umbral de seguridad (ej. 20 cm), el algoritmo interrumpe el avance recto.

04

Maniobra de Evasión

Arduino envía señales al Puente H L298N para retroceder, girar y buscar una vía despejada.

Materiales y Componentes

Arduino UNO / Nano Cerebro del robot encargado de procesar sensores y controlar actuadores.
Sensor Ultrasónico HC-SR04 Mide la proximidad de objetos por medio de ondas de ultrasonido.
Driver Puente H L298N Módulo de potencia para controlar velocidad y sentido de giro de los motores DC.
Chasis de Metacrilato con 2/4 Motores DC Estructura física, ruedas de tracción y Rueda Loca omnidireccional.
Pack Baterías 18650 Li-Ion (7.4V) Fuente de alimentación dedicada de alta descarga.

Código Fuente C++ (Arduino)

const int trigPin = 9;
const int echoPin = 10;

const int IN1 = 5;
const int IN2 = 6;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(IN1, OUTPUT);
  pinMode(IN2, OUTPUT);
}

void loop() {
  long duracion, distancia;
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  duracion = pulseIn(echoPin, HIGH);
  distancia = duracion * 0.034 / 2;

  if (distancia < 20) {
    digitalWrite(IN1, LOW);
    digitalWrite(IN2, HIGH);
  } else {
    digitalWrite(IN1, HIGH);
    digitalWrite(IN2, LOW);
  }
}
