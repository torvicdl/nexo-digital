Carro Autónomo Esquivador de Obstáculos

Un prototipo sobre ruedas que armamos y programamos para que detecte paredes y objetos en tiempo real, esquivándolos por sí solo sin control manual.

C++ / Arduino IDE Sensor HC-SR04 Puente H L298N Baterías 18650 (7.4V)

¿Cómo toma decisiones el robot?

La lógica que programamos sigue un flujo continuo al encontrarse con obstáculos:

Fase 1

Barrido Ultrasónico

El sensor HC-SR04 dispara pulsos de sonido de alta frecuencia de manera constante hacia el frente.

Fase 2

Retorno y Medición

El sonido rebota en cualquier objeto cercano y vuelve al sensor indicando el tiempo transcurrido.

Fase 3

Proceso en Arduino

La placa traduce el tiempo a centímetros exactos y evalúa si hay peligro de colisión cercana.

Fase 4

Maniobra evasiva

Si la distancia baja de 20 cm, el motor invierte su giro mediante el Puente H para buscar un camino libre.

Componentes y Hardware

Las piezas físicas y electrónicas que integran nuestro circuito:

Placa Arduino Uno

Microcontrolador principal que procesa la lógica.

Chasis y 2 Motores

Estructura de acrílico con tracción trasera.

Puente H L298N

Módulo controlador de potencia para motores.

Sensor HC-SR04

Dispositivo de medición por ultrasonido.

Cables Macho-Macho

Puentes para conexiones en protoboard.

Cables Macho-Hembra

Enlaces directos hacia pines de sensores.

2 Baterías 18650

Celdas de litio de alta densidad energética.

Porta Pilas Doble

Soporte con conexión en serie (7.4V).

Rutina de Control en C++

Extracto del código cargado en el Arduino IDE:

const int trigPin = 9;
const int echoPin = 10;
const int motorIzq = 5;
const int motorDer = 6;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(motorIzq, OUTPUT);
  pinMode(motorDer, OUTPUT);
}

void loop() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duracion = pulseIn(echoPin, HIGH);
  int distancia = duracion * 0.034 / 2;

  if (distancia < 20 && distancia > 0) {
    digitalWrite(motorIzq, LOW);
    digitalWrite(motorDer, HIGH);
    delay(400);
  } else {
    digitalWrite(motorIzq, HIGH);
    digitalWrite(motorDer, HIGH);
  }
}
