Carro Autónomo Esquivador de Obstáculos

Un prototipo sobre ruedas que armamos y programamos para que detecte paredes y objetos en tiempo real, esquivándolos por sí solo sin que tengamos que controlarlo.

C++ / Arduino IDE • Sensor HC-SR04 • Puente H L298N • Baterías 18650 (7.4V)

¿Cómo toma decisiones el robot?

Lo programamos para que siga una lógica súper sencilla de 4 pasos:

01

Disparo de ultrasonido

El sensor manda una onda invisible hacia enfrente para medir qué tan libre está el camino.

02

Rebote de la señal

Si hay un objeto o pared, la onda rebota y regresa de inmediato al sensor.

03

Cálculo en la placa

El Arduino mide exactamente cuántos milisegundos tardó en volver y calcula la distancia en centímetros.

04

Esquive automático

Si la distancia es menor a 20 cm, el motor gira hacia un lado para librar el obstáculo y seguir avanzando.

Soporte que suma los 7.4V de alimentación.

Código en Arduino IDE

La rutina principal en C++ cargada en el robot:

const int trigPin = 9;
const int echoPin = 10;
const int motorIzq = 5;
const int motorDer = 6;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(motorIzq, OUTPUT);
  pinMode(motorDer, OUTPUT);
}

void loop() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duracion = pulseIn(echoPin, HIGH);
  int distancia = duracion * 0.034 / 2;

  if (distancia < 20 && distancia > 0) {
    digitalWrite(motorIzq, LOW);
    digitalWrite(motorDer, HIGH);
    delay(400);
  } else {
    digitalWrite(motorIzq, HIGH);
    digitalWrite(motorDer, HIGH);
  }
}
